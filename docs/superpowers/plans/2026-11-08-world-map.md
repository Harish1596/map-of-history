# Classroom World Map Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for inline execution.

**Goal:** Replace the Antioch home screen with the approved classroom world map.

**Architecture:** MapLibre renders local country polygons and label points in
one camera. React owns loading/error feedback and accessible navigation controls.
Keep the prior history components and JSON for future work.

**Tech Stack:** Existing Next.js static export, React, TypeScript and MapLibre.

**Spec:** `docs/superpowers/specs/2026-11-08-world-map-design.md`.

## Global Constraints

- No runtime APIs, databases or external map/font requests.
- Preserve the selected preview's full-screen layout and sage geography.
- Use actual dataset boundaries and labels, not generated image geography.
- Preserve the Antioch records for later development.

## Review Focus

- Small-country labels: collision detection and zoom reveal legible names.
- Resize and touch navigation: map fills the available viewport without overflow.
- Asset failures and WebGL failures: actionable error feedback replaces loading.
- Reset after panning: restores a complete world overview at the current size.
- External network requests: all map and font assets resolve locally.
